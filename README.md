# Netflix ピクチャー イン ピクチャー拡張機能

Netflixの再生画面で以下の2つの方法からピクチャー イン ピクチャー(PiP)を起動できるChrome拡張機能です。

1. 動画上を右クリック → 「ピクチャー イン ピクチャー」を選択
2. 再生コントロールバー(右下、全画面ボタンの隣)に表示されるPiPアイコンをクリック
   - コントロールバーの検出に失敗した場合は、画面右下に丸いボタンが常時表示されます

## インストール方法(開発者モードでの読み込み)

1. このフォルダを解凍し、好きな場所に置く
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をONにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このフォルダ(`netflix-pip-extension`)を選択する
5. Netflixの動画再生ページを開く(または既に開いている場合はリロードする)

## 注意事項

- NetflixのUI(クラス名など)は予告なく変更されることがあるため、コントロールバーへのボタン設置がうまくいかない場合があります。その場合でも右クリックメニューおよび画面右下のフローティングボタンからPiPは利用できます。
- PiP自体はブラウザ標準の `Document.pictureInPictureElement` / `HTMLVideoElement.requestPictureInPicture()` を利用しているため、Netflix側の仕様変更やDRMの都合で動作しない場合があります。
- 個人利用目的のローカル拡張機能です。Chromeウェブストアへの公開は想定していません。
